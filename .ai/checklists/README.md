# Checklists

Quality gates for NDC development processes. Use these before marking a task complete.

## Available checklists

| Checklist | When to use |
|---|---|
| `pre-deploy` | Before any staging or production deploy |
| `pr-review` | Before requesting or approving a PR |
| `security-review` | During security audit of a changeset |
| `accessibility` | For any frontend UI change |
