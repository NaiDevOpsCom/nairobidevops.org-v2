# React Standards

## Component Types

### Pages (`client/src/pages/`)

- One file per route, named after the page (e.g. `Home.tsx`, `AboutUs.tsx`, `jobs.tsx`)
- Each page is a default-exported function component
- Pages own data fetching via hooks, compose UI from components

```typescript
function Home() {
  const { data: jobs } = useJobs();
  return (
    <div>
      <HeroSection />
      <JobList jobs={jobs} />
    </div>
  );
}
```

### UI Components (`client/src/components/ui/`)

- Generated by shadcn. Do not edit unless necessary.
- 51 primitives: button, card, dialog, dropdown, form, input, modal, toast, tooltip, etc.
- Import from `@/components/ui/` path alias.

### Custom Components (`client/src/components/`)

- Project-specific components: `Navbar`, `Footer`, `SEO`, `CloudinaryImage`, `SponsorsCarousel`
- Each is a named function component with explicit prop types
- Support dark mode via ThemeContext where applicable

## Hooks (`client/src/hooks/`)

- Custom hooks for data fetching and logic encapsulation
- Naming: `use<Purpose>` (e.g., `useJobs`, `useLumaEvents`, `useToast`)
- Data fetching hooks use TanStack React Query internally

```typescript
export function useJobs() {
  return useQuery({
    queryKey: ['jobs'],
    queryFn: () => fetch('/endpoints?action=jobs').then(r => r.json()),
  });
}
```

## Contexts

- Currently one context: `ThemeContext` (dark/light mode)
- New global states should use React Context, not prop drilling
- Context providers wrap the app in `App.tsx`

## Data Fetching with TanStack Query

```typescript
import { useQuery, useMutation } from '@tanstack/react-query';

// Read
const { data, isLoading, error } = useQuery({
  queryKey: ['jobs', filters],
  queryFn: () => fetchJobs(filters),
  staleTime: 30_000,
});

// Write
const mutation = useMutation({
  mutationFn: (newJob) => submitJob(newJob),
  onSuccess: () => queryClient.invalidateQueries({ queryKey: ['jobs'] }),
});
```

## Routing with Wouter

```typescript
import { Switch, Route, useLocation, Link } from 'wouter';

// Hash-based routing (configured in App.tsx)
<Switch>
  {routes.map((route) => (
    <Route key={route.path} path={route.path} component={PageComponent} />
  ))}
  <Route component={NotFound} /> {/* 404 fallback */}
</Switch>

// Navigation
const [, setLocation] = useLocation();
setLocation('/about');

<Link href="/jobs">Jobs</Link>
```

## Error Handling

- Wrap each page section with `<ErrorBoundary>` for graceful failure
- Show loading states during data fetching
- Use react-helmet-async for dynamic page titles and meta tags
- Never swallow errors silently — log them in dev, show user-friendly messages in prod

## Tailwind Usage

- Use Tailwind utility classes, not inline styles
- Use CSS variables from tailwind config for colors: `bg-background`, `text-foreground`, `text-primary`
- Respect dark mode: `dark:bg-muted dark:text-muted-foreground`
- Define complex animations in tailwind config
